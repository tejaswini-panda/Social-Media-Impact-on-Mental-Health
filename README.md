# Social Media Impact on Mental Health

## Project Overview
This project explores the relationship between social media usage and mental health indicators using data analysis and visualization techniques.

## Objectives
- Analyze social media usage patterns.
- Explore relationships between usage habits and mental health indicators.
- Identify trends and patterns in the dataset.
- Present findings through interactive visualizations.

## Tools & Technologies
- Power BI
- Excel
- Data Cleaning
- Data Analysis
- Data Visualization

## Key Analysis
- Social media usage patterns.
- Time spent on social media.
- Mental health indicators.
- Relationships between usage and reported well-being.
